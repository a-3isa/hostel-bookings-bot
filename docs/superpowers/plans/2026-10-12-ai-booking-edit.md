# AI booking edit Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** An admin taps a new main-menu button, types a booking change in free text, sees exactly what would change, and nothing is written until they tap Confirm.

**Architecture:** An Information Extractor node (Anthropic Chat Model sub-node) sits in front of the `Brain` Code node and turns the typed text into a small JSON intent. It has no tools and never writes. `brain.js` validates the intent, looks the booking up in the already-loaded rows, applies it through the same setters the manual edit menu uses, and draws the existing `EDIT_CONFIRM` review card. Confirm runs the unchanged `commitEdit` path.

**Tech Stack:** n8n workflow generated by Python (`build_workflow.py`, `deploy_graph.py`), `brain.js` (a Code-node state machine tested offline with `node test_brain.mjs`), pytest, Anthropic Messages API (evaluation script only).

**Spec:** `docs/superpowers/specs/2026-10-12-ai-booking-edit-design.md` (approved; the amendments in Task 12 Step 1 record four small deviations found while planning).

## Global Constraints

- Admins only. The button is rendered only for admins, `choice_ai` is guarded by `isAdmin` in both dispatch places, and the `AI_TEXT` case re-checks `isAdmin`.
- The model **parses only**: no tools, no writes. Brain re-validates every field; the booking always comes from a row lookup, never from the model.
- Model id `claude-haiku-5-5`, credential type `anthropicApi`, node types `@n8n/n8n-nodes-langchain.informationExtractor` v1.2 and `@n8n/n8n-nodes-langchain.lmChatAnthropic` v1.6. Confirm the model id appears in the node's model list once the credential exists; Sonnet is the fallback.
- Methods offered to the model: `cash, instapay, airbnb, vcash, eur, usd`. Never `unpaid`.
- Foreign money: the method is the **currency** (`100 usd cash` is `usd`). `eur`/`usd` amounts stay on a payment line of their own, as `paymentTarget` already does.
- The sheet's formula columns `تاريخ المغادرة, نسبة البرنامج, المتبقي, تاريخ الإدخال, صافي الدخل, آخر تعديل` are never written. Only `عدد الليالي` changes for a stay.
- `AI_TEXT` and `AI_PICK` go into **both** `BOOKING_STATES` and `LOCATION_STATES`, in **both** `build_workflow.py` and `deploy_graph.py`.
- Conflicts are a warning, never a block: same `conflict_warning` / `conflict_line` strings as `showConfirm()`, Confirm relabelled `btn_confirm_anyway`.
- Scope is payment, room change, extend / until / leave. Not price, arrival date, notes, cancelling, cashier access, or finding a booking by name.
- The graph is generated. Never edit the workflow in the n8n editor; change `build_workflow.py` / `deploy_graph.py` and regenerate.

## Review Focus

Failure modes the spec implies but a straight reading of it would not test. Each is pinned by a test in the task named.

1. **Extending a stay whose nights cell is blank or not a number** (the older fixtures have no `عدد الليالي` at all). Expected: a clear refusal, never `NaN` written to the sheet. Task 5.
2. **Typing text while the review card is on screen.** Expected: the "use the buttons" nudge, nothing saved, and no second model call. Task 4.
3. **A photo, file or `/command` arriving in `AI_TEXT`.** Expected: ignored (or handled as the command), never reported as "AI unavailable". Task 1 (photo) and Task 7 (`/start`).
4. **Arabic-Indic digits in the ID the model returns** ("٣١"). Expected: finds booking 31. Task 3.
5. **The same ID on two bookings** (IDs restart each month). Expected: the existing pick list, and the stored request survives the session round-trip and is applied to the booking picked. Task 3.

```js
/**
 * The model's answer for an AI_TEXT message, checked field by field. Task 3
 * fills in the checks; until then anything the model returns is "not understood".
 * `item` is the AI Extract node's item: { output } on success, whatever n8n
 * puts there on an error, or null when the node did not run.

function readAiIntent(item) {
  const o = item && item.output;
  if (!o || typeof o !== 'object') return { fail: 'ai_unavailable' };
  return { fail: 'ai_not_understood' };
}

function replyAiFail(got) {
  if (got.fail === 'ai_not_understood') {
    reply(t('ai_not_understood', { reason: got.reason ? `\n(${got.reason})` : '' }));
  } else {
    reply(t(got.fail));
  }
}
```

```js
/**
 * A stay change from the request. Only عدد الليالي is written; تاريخ المغادرة is
 * the sheet's own J + I formula, so `d.departure` exists to show the date on the
 * card and in the group message, exactly as the checkout question does.
 * Returns null when applied, or the text to refuse with.
 */
function applyAiStay(stay) {
  const o = d.editOrig || {};
  const arrival = String(o['تاريخ البداية'] || '').trim();
  if (!validIsoDate(arrival)) return t('ai_no_arrival');
  let nights;
  if (stay.kind === 'extend') {
    const raw = o['عدد الليالي'];
    // An open-ended stay's nights is a live =TODAY()-J formula; extending it
    // would replace the formula with a fixed number.
    if (String(raw === undefined || raw === null ? '' : raw).trim().startsWith('=')) {
      return t('ai_open_ended');
    }
    const cur = parseNum(raw);
    if (cur === null) return t('ai_nights_unknown');
    nights = Math.trunc(cur) + stay.nights;
  } else {
    const date = stay.date || todayIso();
    nights = daysBetween(arrival, date);
    if (nights === null) return t('ai_bad_date');
    if (nights < 0) return t('ai_departure_before', { departure: date, arrival });
  }
  editSet(d, 'عدد الليالي', nights);
  d.departure = isoAddDays(arrival, nights);
  return null;
}
```

```js
function applyAiRoom(room) {
  const reg = locationRegistry();
  const entry = reg.find(e => sameName(e.apartment, room.apartment));
  if (!entry || entry.rooms.indexOf(room.room) === -1) {
    return t('ai_room_unknown', { list: reg.map(e => e.apartment).join('، ') });
  }
  editSet(d, 'اسم الشقة', entry.apartment);
  editSet(d, 'رقم الغرفة', Number(room.room));
  return null;
}

/**

 * Must run on a turn whose state loaded the bookings (AI_TEXT / AI_PICK); the
 * result is stored as text because the card may be drawn two turns later, after
 * a receipt, when bookingRows() is empty. The booking itself is skipped by row.

function aiClashText(dd) {
  const o = dd.editOrig || {};
  const eff = (col) => (dd.editNew && dd.editNew[col] !== undefined ? dd.editNew[col] : o[col]);
  const arrival = String(eff('تاريخ البداية') || '').trim();
  const rawNights = eff('عدد الليالي');

    .trim().startsWith('=');
  const nights = parseNum(rawNights);
  if (!validIsoDate(arrival) || (!open && nights === null)) return '';
  const apartment = eff('اسم الشقة');
  const room = eff('رقم الغرفة');
  const clashes = findConflicts(apartment, room, arrival, Math.trunc(nights || 0), open, dd.editRow);
  return clashes.length ? conflictBlock(apartment, room, clashes) : '';
}
```

```python
def ai_branch_ops(have, conns, anthropic):
    """Operations that add the AI edit: a gate and an extractor in front of the
    Brain, and the chat model plugged into the extractor.

    Idempotent against `have` (live node names) and `conns` (live connections).
    Returns (ops, bindings); a binding is (node, credential key, id, name) and is
    applied after its node exists.

    With no Anthropic credential on the instance the branch is skipped: wiring the
    Brain through an extractor that cannot authenticate would make the bot look
    dead, whereas without the nodes the Brain answers "unavailable" by itself.
    """
    ops, bindings = [], []
    if anthropic is None:
        print("  ! AI edit skipped — no Anthropic credential on the instance."
              " Create one in n8n (Credentials -> Anthropic) and run this again.")
        return ops, bindings

    def link(src, tgt, index=0, kind="main"):
        existing = [c["node"] for br in conns.get(src, {}).get(kind, [])[index:index + 1]
                    for c in br]
        if tgt in existing:
            return
        op = {"type": "addConnection", "source": src, "target": tgt,
              "sourceIndex": index, "targetIndex": 0}
        if kind != "main":
            op["connectionType"] = kind
        ops.append(op)

    def unlink(src, tgt, index=0):
        branches = conns.get(src, {}).get("main", [])
        if index < len(branches) and any(c["node"] == tgt for c in branches[index]):
            ops.append({"type": "removeConnection", "source": src, "target": tgt,
                        "sourceIndex": index, "targetIndex": 0})

    specs = (
        ("Needs AI?", "n8n-nodes-base.if", 2.3, bw.needs_ai_params(), [800, 640]),
        ("AI Extract", "@n8n/n8n-nodes-langchain.informationExtractor", 1.2,
         bw.ai_extract_params(), [1040, 640]),
        ("Anthropic Chat Model", "@n8n/n8n-nodes-langchain.lmChatAnthropic", 1.6,
         bw.ai_model_params(), [1040, 820]),
    )
    for name, ntype, tv, params, pos in specs:
```

```python
"""Does the model read real staff phrasing the way brain.js expects?

The offline suite mocks the model, so it cannot tell. This sends each case in
ai_eval_cases.json to the Anthropic API exactly as the n8n node does (a forced
tool call whose input schema is ai_intent.SCHEMA) and compares the answer.

    ANTHROPIC_API_KEY=sk-ant-... python booking_bot/eval_ai_intents.py
    ANTHROPIC_API_KEY=... python booking_bot/eval_ai_intents.py --model claude-sonnet-5-5

Add the phrases your staff really type to ai_eval_cases.json. A case passes when
every key in `want` matches; `null` means "must be absent", and "*" means
"present and non-empty". Keys not named in `want` are not checked.
"""

import argparse
import json
import os
import sys
import urllib.error
import urllib.request

sys.path.insert(0, os.path.dirname(os.path.abspath(__file__)))

import ai_intent

for _stream in (sys.stdout, sys.stderr):
    try:
        _stream.reconfigure(encoding="utf-8", errors="replace")
    except (AttributeError, ValueError):
        pass

HERE = os.path.dirname(os.path.abspath(__file__))
EVAL_TODAY = "2026-10-12"
APARTMENTS = ["ذاكر حسين", "احمد فهيم", "انبي 3", "انبي 2", "ابو حديد 11", "عبدالله العربي"]
URL = "https://api.anthropic.com/v1/messages"


def ask(model, text, key):
    body = {
        "model": model,
        "max_tokens": 300,
        "system": ai_intent.render_prompt(EVAL_TODAY, APARTMENTS),
        "tools": [{"name": "extract", "description": "Record the edit request.",
                   "input_schema": ai_intent.SCHEMA}],
        "tool_choice": {"type": "tool", "name": "extract"},
        "messages": [{"role": "user", "content": text}],
    }
    req = urllib.request.Request(
        URL, data=json.dumps(body).encode("utf-8"), method="POST",
        headers={"x-api-key": key, "anthropic-version": "2023-06-01",
                 "content-type": "application/json"})
    try:
        with urllib.request.urlopen(req, timeout=60) as resp:
            data = json.load(resp)
    except urllib.error.HTTPError as err:
        sys.exit(f"HTTP {err.code}: {err.read().decode('utf-8', 'replace')[:400]}")
    for block in data.get("content", []):
        if block.get("type") == "tool_use":
            return block["input"]
    return {}


def matches(got, want):
    for k, v in want.items():
        have = got.get(k)
        if v is None:
            if have:
                return False
        elif v == "*":
            if not have:
                return False
        elif isinstance(v, dict):
            if not isinstance(have, dict) or not matches(have, v):
                return False
        elif have != v:
            return False
    return True


def main():
    ap = argparse.ArgumentParser()
    ap.add_argument("--model", default=ai_intent.MODEL)
    args = ap.parse_args()
    key = os.environ.get("ANTHROPIC_API_KEY")
    if not key:
        sys.exit("set ANTHROPIC_API_KEY")
    with open(os.path.join(HERE, "ai_eval_cases.json"), encoding="utf-8") as fh:
        cases = json.load(fh)

    failed = 0
    for case in cases:
        got = ask(args.model, case["text"], key)
        ok = matches(got, case["want"])
        failed += not ok
        print(f"{'ok  ' if ok else 'FAIL'} {case['text']}")
        if not ok:
            print(f"       want {json.dumps(case['want'], ensure_ascii=False)}")
            print(f"       got  {json.dumps(got, ensure_ascii=False)}")
    print(f"\n{len(cases) - failed}/{len(cases)} read as expected ({args.model})")
    sys.exit(1 if failed else 0)


if __name__ == "__main__":
    main()
```
